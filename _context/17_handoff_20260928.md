  он должен сделать руками, — внутрь вопроса или последним сообщением;

  `manual-steps-visible`).
- Пользователь может сам сменить стенд (переткнуть кабели) по ходу работы:
  признак — `carrier off/on` в `dmesg` и чужие MAC в `ip neigh`.
- Windows: сеть от прибора «Общедоступная», входящий echo закрыт; на echo к
  `ff02::1` не отвечает вовсе; метрика проводного адаптера 5 против 50 у Wi-Fi.
  Настройки защиты Windows меняет только пользователь.
- `iperf3` сервер не привязан к адресу: по UDP IPv6 хост с несколькими
  адресами отвечает с другого → `-B <адрес>`.
- `rx_missed` в r8152 16-битный; дельта по модулю 65 536.
- `csv.writer` пишет CRLF; git предупреждает, это нормально.
- Старые записи DHCP в `/run/analyzer/dnsmasq_<порт>.leases` живут 12 ч после
  ухода хоста; `targets.alive()` проверяет адрес заново.
- В `ps … | grep` шаблон ловит сам себя и командную строку ssh — искать
  `grep "^iperf3"` в выводе `ps -eo args`.
