## Чего на фото нет

Для модели корпуса по снимкам не определить и мерить штангенциркулем придётся
всё равно:

- координаты каждого разъёма от одного угла платы Pi по двум осям;
- межцентровые расстояния монтажных отверстий и их диаметр;
- высоту RJ45 и USB над поверхностью платы;
- зазор между платами точнее, чем «на глаз по линейке»;
- вылет microSD за край платы.

## Соглашение

Новые фото железа класть сюда же, с говорящим именем и строкой в этой таблице.
Иначе через две сессии никто не вспомнит, что на снимке.

Имя файла скриншота содержит кириллицу и пробел. Для LaTeX и git это неудобно,
но в тексте работы он не используется, так что переименование не срочное.
