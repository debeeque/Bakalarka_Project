## 2. Бэклог софта, порядок предложен 26.09 (приоритет — софт)

1. **Метрики в панели сниффинга + экспорт + имена сервисов.** Идеи из
   разбора Network Traffic Analyzer (LinkedIn/GitHub, `04_external_refs.md`)
   и пункт 9 плана: пакеты/с, средний размер пакета, доли TCP/UDP/ICMP/IPv6,
   уникальные хосты, топ отправителей; кнопки сохранения захвата в PCAP
   (`wrpcap()`) и CSV; имя сервиса через `socket.getservbyport()`. Даёт
   таблицу чисел в *Zhodnocení* и свежий скриншот. Фильтр захвата — BPF в
   ядре, не в Python (теория 2.3 это требует).
2. **Постоянные имена портов и горячее подключение адаптеров:** правило udev
   по MAC. Сейчас eth1/eth2 меняются местами между загрузками (см.
   `CLAUDE.md`), мешает воспроизводимости. Туда же: при подключении адаптеров
   к работающему прибору порты должны подниматься сами. Найдено 26.09 вечером:
   малина загрузилась без адаптеров (в `lsusb` их нет), `analyzer-ports`
   прождал устройства 90 с и ушёл в `failed` — поведение верное, но после
   того как адаптеры воткнут, порты поднимет только перезагрузка или кнопка
   DHCP (режим `dhcp` сам вызывает `ports`, если namespace нет).
   Попутно: приветственный экран раз в 3 с зовёт `sudo ip -n ...`, каждый
   вызов пишет строку в журнал; стоит читать состояние линков без `sudo` или
   реже.
3. **Отложенные функции от 03.08:** диагностика порта (`ethtool`: скорость,
   дуплекс, автосогласование; `ethtool` лежит в `/usr/sbin`, нужен `sudo`),
   LLDP/CDP (сначала проверить, включён ли на коммутаторах в EB215), VLAN,
   UDP с потерями и джиттером (`iperf3 -u`), тест Path MTU, выгрузка отчёта
   на флешку.
4. **Калибровка тача** `xinput_calibrator` — нужны касания пользователя.
5. **Часовой пояс Europe/Prague** — спрошено 26.09, ответа нет. Важно для
   меток времени в экспорте и логах.
6. **Пересъёмка скриншотов `scrot`** — только когда GUI окончательный, одним
   проходом (решение от 03.08 и 14.08).
7. Мелочь: `cloud-init` съедает ~6 с загрузки. Отключать только после

## 4. Подводные камни, на которые наступили в этой сессии

- **SSH с Acer:** имя `raspberrypi.local` временами не резолвится. Обход:
  `ssh -o HostName=<IP> -o HostKeyAlias=raspberrypi.local malina`. IP искать
  `Get-NetNeighbor` по MAC `b8-27-eb-9b-1b-43`. Проверку ключа не отключать.
- **`pgrep -f` находит сам себя**, если искомая строка есть в его командной
  строке. Использовать `pgrep -x` или шаблон с `^`.
- **Перезапуск GUI киоска:** `pkill -f "^python3 gui_app.py"`, `.xinitrc`
  поднимет его через 2 с. GUI, запущенный с рабочего стола, идёт с полным
  путём и этим шаблоном не ловится.
- **Второй экземпляр GUI для скриншотов и проверки кнопок:** маленький
  харнесс в `/tmp` с `PYTHONPATH=~/diploma_project`, `DISPLAY=:0
  XAUTHORITY=$(ls /tmp/serverauth.*)`, методы вызываются напрямую; снимок
  `scrot -o`. Для диалогов `root.withdraw()`.
- **Ожидание по SSH** должно отличать «служба закончилась» от «SSH не
  ответил», иначе сбой сети выглядит как конец работы.
- **`.xinitrc` менять только через новый файл + `mv`**: запущенный `sh`
  читает скрипт по ходу выполнения.
- **Код на устройстве только ASCII** (приложения работы через `listings`).
  Инструмент правки превращает `\u0160` и подобные экранирования в настоящие
  символы — после правок проверять `LC_ALL=C grep -P '[^\x00-\x7F]'` и
  чинить через `chr()` в Python.
- **Концы строк:** `.gitattributes` держит LF для `.py`, `.sh`, `.service`,
  `.conf`, `.csv` и всего `SourceCodes/system/`. CRLF в unit-файле или
  `.xinitrc` сломает их на малине.
- **`/tmp` на малине — tmpfs, журнал systemd не сохраняется** между
  загрузками. Всё, что должно пережить перезагрузку, писать в `/home` или
  `/var/log`.
- **`nmcli` для скана и подключения требует `sudo`** (polkit `auth`).
- **Переключение Wi-Fi из GUI рвёт SSH-сессию** — такие проверки делает
  пользователь руками и в конце возвращает малину на `Benswagin`.
- Скрипты, которые ненадолго рвут связь (замер с выключением Wi-Fi), гонять
  службой `systemd-run` с самовосстановлением.
