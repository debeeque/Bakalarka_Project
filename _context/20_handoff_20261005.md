  `kill` GUI, `pkill -x lxsession`).
- Малина перезагружалась без нас (зарядка, адаптеры): `/tmp` пустеет, часы до
  NTP показывают время fake-hwclock (в `ups_events.log` событие `start` с
  чужой датой).
- RTL8153 держит физический линк при `ip link set down` (и с WoL off): «нет
  линка» проверяется только кабелем руками. `ethtool -p` не поддерживается.
- После стенда с RA ядро строит на mon0 SLAAC и маршрут из префикса snd0 —
  снимать руками, иначе на петле пропадает изоляция по IPv6.
- `pkill -f <шаблон>` внутри `ssh malina '…'` убивает саму сессию, если
  шаблон есть в её командной строке.
- Bash-инструмент съедает `\\` даже в heredoc с кавычками: правки `.tex` и
  Python-скрипты с обратными слешами — через Edit или файл от Write.
- TikZ внутри меток enumitem не работает с русским babel.
- В экранах не называть поля как методы базового класса (`running`, `idle`,
  `log`, `bottom`) — `self.running = None` молча сломал START.
