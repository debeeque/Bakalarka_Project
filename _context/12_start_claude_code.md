## Разрешения

`.claude/settings.local.json` (не коммитится, живёт только на Acer)
заранее разрешает `ssh malina`, `scp`, `md5sum` и чтение git, чтобы
проверки не упирались в подтверждение каждой команды. `git push` и всё
остальное Claude Code спросит. Если файл мешает, его можно удалить.
