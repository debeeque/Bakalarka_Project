## Софт на устройстве

Каталог на малине: `~/diploma_project/` (пользователь `muk0015`)

| Файл | Что делает |
|---|---|
| `setup_network.sh` | bash: создаёт netns `analyzer_monitor` / `analyzer_sender`, перекидывает туда `eth1`/`eth2`, назначает IP |
| `gui_app.py` | Tkinter GUI «Portable Network Analyzer», 800×480, вся логика управления |
| `arp_scan.py` | ARP-скан через Scapy |
| `capture.pcap` | пример захвата |

**Ключевая идея архитектуры:** логическая изоляция двух тестовых портов через
**Linux Network Namespaces (netns)** — это главный технический вклад работы.

Адресация:
- `analyzer_monitor` → `eth1` → `10.0.1.10/24`, цель `10.0.1.20`
- `analyzer_sender` → `eth2` → `10.0.2.10/24`, цель `10.0.2.20`

Функционал GUI (что реально работает):
- пассивный сниффинг + счётчик трафика в реальном времени (TCP / UDP / ICMP, детект IPv6)
- ARP-скан
- измерение пропускной способности через **iperf3** (v4 и v6) — важно: `iperf3`, не `iperf`
- ping v4 / v6
- **Nmap**: LAN-скан и Wi-Fi-скан (добавлено позже, по своей инициативе)
- виртуальная экранная клавиатура + **нумпад** для ввода IP пальцем (без физической клавы)

## Нерешённое / слабые места

- **Автономность не доведена до конца.** Главное правило проекта — на целевом ПК
  ничего настраивать не надо. По факту на «жертве» всё ещё приходится вручную
  поднимать порты (`ip link set ... up`) и запускать `dhclient`. Научрук просил
  сделать автоприсвоение `10.0.1.20` / `10.0.2.20` со стороны устройства.
- Nmap-скан на `10.0.1.20` не даёт результатов (на `10.0.2.20` работает).
- Нет аккумулятора и корпуса.
- Текст «жидкий» по наполнению. Замеры на 30.03.2026 (последний коммит):

  | Глава | Слов |
  |---|---|
  | `Introduction.tex` — Úvod | 236 |
  | `SampleChapter2.tex` — Teoretická východiska a analýza problematiky | 384 |
  | `SampleChapter1.tex` — Návrh a realizace, zhodnocení výsledků | 796 |
  | `Conclusion.tex` — Závěr | 259 |
  | **Итого** | **~1 675** |

  25 страниц — это примерно **6 000–7 000 слов**. То есть написано около четверти,
  и сильнее всего просела теория (нужно ~10 страниц ≈ 2 500 слов, есть 384).
- `Chapters/TechnicalDetails.tex` — остаток шаблона, в `BachelorThesis.tex` не
  подключён. Либо наполнить, либо удалить.
- `Prilohy` (`Chapters/Appendix1.tex`, `Appendix2.tex`) не наполнены; коды лежат
  отдельно в `SourceCodes/`.
